QA LAB BRASIL - V1.0 PUBLIC RELEASE

Deploy recomendado: Netlify.
1. Publique esta pasta inteira (ou conecte o repositório GitHub ao Netlify).
2. O formulário "qa-lab-contact" usa Netlify Forms e passa a aceitar envios após o deploy.
3. Para receber cada envio também por e-mail: Netlify > Project configuration > Notifications > Form submission notifications > Add notification > Email notification. Selecione o formulário qa-lab-contact e informe o e-mail que receberá os avisos.
4. Faça um envio de teste após o deploy e confirme o recebimento no painel Forms e no e-mail configurado.

Importante: o endereço de e-mail do autor não fica exposto no HTML público.
