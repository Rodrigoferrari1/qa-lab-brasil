# QA Lab Brasil 2.6 — SEO & Discoverability (local)

- URLs amigáveis sem hash (`/testing` em vez de `/#/testing`).
- Fallback SPA configurado no Netlify para acesso direto e refresh.
- SEO base: title, description, canonical, Open Graph, Twitter Card e Schema.org.
- SEO dinâmico por tópico no navegador.
- Sitemap com Home, tópicos e áreas especiais.
- robots.txt apontando para o sitemap.
- Assets e dados com caminhos absolutos para funcionar em URLs internas.
- Sem alterações intencionais de layout, cores ou identidade visual.
- Release preparada para validação local antes de qualquer push para produção.
