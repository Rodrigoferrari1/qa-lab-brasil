# QA Lab Brasil 3.1.3 - Chatbot & Mobile Search UX

Baseline: QA Lab Brasil 3.1.2 production candidate validated and deployed before this maintenance.

Changes only:
- Chatbot moved lower during normal navigation on desktop, notebook, tablet and mobile.
- Chatbot uses one stable visual asset based on the approved Web/Desktop appearance across all breakpoints.
- Chatbot and chat panel are hidden during an active CTFL simulator exam and automatically return outside the runner.
- Mobile/tablet search suggestions are positioned below the real search box, keeping the Search/Pesquisar/Buscar button visible and clickable.
- Desktop/notebook search layout is not changed.

Frozen: simulator content/logic, PDFs, PDF Center, Test Data generator, multilingual content, Forms, Analytics, SEO and navigation content.
