# 🧪 QA Lab Brasil

**Quality Engineering Knowledge Platform**

> Learn. Explore. Practice. Apply.

QA Lab Brasil is an open knowledge platform focused on **Software Quality Assurance, Quality Engineering, Software Testing, Test Automation and Software Engineering**.

The project was created to provide useful content for professionals at different career stages — from people taking their first steps in QA to Senior QA Engineers and QA Leads.

🌐 **Live website:** https://qualityassurance-brasil.netlify.app/

---

## 🎯 Project Purpose

QA Lab Brasil was created to bring together technical knowledge, practical examples, tools and learning resources commonly used in the daily work of software quality professionals.

The platform combines:

- 📚 Learning
- 🔎 Quick technical reference
- 🧪 Practice
- 🧰 QA utilities
- 🤖 Artificial Intelligence applied to QA

The goal is not only to explain concepts, but also to show **how they can be applied in real software projects**.
