# QA Lab Brasil 3.1 - Simulator Fixed Navigation Local

Local-only review fix. No production deploy performed.

## Change
- CTFL simulator navigation is now persistent at the bottom of the viewport.
- Previous / Back to simulators / Next remain visible while question content scrolls.
- On the final question, Next is replaced by Finish in the same fixed position.
- Extra bottom spacing prevents the fixed controls from covering answers or the review checkbox.
- Responsive behavior is included for desktop, notebook and mobile.
